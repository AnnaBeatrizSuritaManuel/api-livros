🌸 Sobre o projeto

Este projeto consiste no desenvolvimento de uma API de Livros, realizado como trabalho avaliativo para nota do 3º bimestre da ETEC.

O trabalho foi dividido em 4 etapas, sendo que cada etapa corresponde ao conteúdo e às atividades desenvolvidas em uma aula.

A proposta é desenvolver o projeto de forma gradual, aplicando os conhecimentos aprendidos durante as aulas e acompanhando a evolução da API ao longo das etapas.

💗 Etapas do trabalho
Etapa	Descrição
💜 01	Primeira etapa do desenvolvimento da API
🌷 02	Segunda etapa do desenvolvimento da API
💗 03	Terceira etapa do desenvolvimento da API
💜 04	Quarta e última etapa do desenvolvimento da API

✨ Cada etapa foi desenvolvida em uma aula, fazendo parte da construção progressiva do projeto.

🎓 Sobre mim

Sou aluna da ETEC MCM e atualmente estou no 3º ano do Ensino Médio.

Este projeto faz parte das atividades escolares realizadas durante o 3º bimestre e tem como objetivo colocar em prática os conhecimentos adquiridos nas aulas relacionadas ao desenvolvimento de APIs.

🛠️ Tecnologias utilizadas

As tecnologias utilizadas neste projeto incluem:

💜 Linguagem
Python 3.11 ou superior
🌸 Frameworks e bibliotecas
FastAPI — framework utilizado para criação da API;
Uvicorn — servidor utilizado para executar a aplicação;
SQLAlchemy — biblioteca utilizada para comunicação com o banco de dados;
PyMySQL — driver utilizado para conectar o Python ao MySQL;
Pydantic Settings — utilizado para leitura e validação das configurações;
Python Dotenv — utilizado para auxiliar na leitura das variáveis do arquivo .env.
💗 Banco de dados
MySQL — banco de dados relacional utilizado no projeto;
phpMyAdmin — utilizado para gerenciamento do banco de dados;
XAMPP — utilizado para executar o MySQL e o Apache localmente.
🌷 Ferramentas
Visual Studio Code — editor utilizado para desenvolver o projeto;
Git — utilizado para controle de versão;
GitHub — utilizado para armazenar o projeto e acompanhar sua evolução.
📚 Objetivo

O principal objetivo deste trabalho é desenvolver uma API funcional para gerenciamento de livros, enquanto aplico, na prática, os conceitos aprendidos durante as aulas.

Além disso, a divisão em quatro etapas permite acompanhar a evolução do projeto e colocar em prática cada novo conteúdo apresentado ao longo das aulas.

Na primeira etapa, o foco está na preparação do ambiente, configuração do banco de dados MySQL e criação da conexão entre a aplicação e o banco.

💕 Considerações finais

Este projeto representa uma parte do meu aprendizado durante o 3º ano do Ensino Médio na ETEC MCM, reunindo os conhecimentos desenvolvidos ao longo das aulas do 3º bimestre.

Através deste trabalho, tenho a oportunidade de colocar em prática conhecimentos relacionados ao desenvolvimento de APIs, Python, bancos de dados, FastAPI e controle de versão com Git e GitHub.
